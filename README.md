
# 📱 Resale Phone Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts the resale price of used mobile phones using Machine Learning techniques. It involves data preprocessing, feature engineering, model training, and price prediction.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Random Forest Regressor
- Jupyter Notebook

## 📊 Machine Learning Workflow
- Data Collection
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Model Evaluation
- Price Prediction

## 📁 Dataset
Used Mobile Phone Dataset
